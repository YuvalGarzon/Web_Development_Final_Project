# Afeka Trip Planner 2026

A full-stack web application for planning hiking and cycling trips with AI-generated routes, real-time weather forecasts, and interactive maps.

**Built by:** Yarin Shushan & Yuval Garzon

---

## Features

- **AI-Generated Routes** — Hiking (5–10km circular) or cycling (30–70km city-to-city) routes generated by LLM
- **3-Day Weather Forecast** — Live weather data for each route
- **Interactive Map** — Leaflet map with named waypoints via reverse geocoding (Photon/Komoot)
- **Trip History** — Save, view, duplicate, and delete past trips
- **Authentication** — JWT-based auth (access + refresh tokens) with httpOnly cookies
- **User Accounts** — Register with first/last name, login, logout

## Setup

### 1. Clone and install dependencies

```bash
# Backend
npm install

# Frontend
cd frontend && npm install && cd ..
```

### 2. Create `.env` in the project root

```env
PORT=4000
NODE_ENV=development

MONGO_URI=mongodb://127.0.0.1:27017/afeka_trip_auth

JWT_ACCESS_SECRET=CHANGE_ME
JWT_REFRESH_SECRET=CHANGE_ME

ACCESS_EXPIRES_IN=1d
REFRESH_EXPIRES_IN=1d

SUBMITTERS=Yarin Shushan & Yuval Garzon

CLIENT_ORIGIN=http://localhost:3000

OPENAI_API_KEY=YOUR_OPENAI_KEY
OPENWEATHER_API_KEY=YOUR_OPENWEATHER_KEY
```

Generate strong JWT secrets:
```bash
python3 -c "import secrets; print('JWT_ACCESS_SECRET=' + secrets.token_hex(32)); print('JWT_REFRESH_SECRET=' + secrets.token_hex(32))"
```

### 3. Start with Docker Compose

```bash
docker compose up -d
```

This starts:
- **MongoDB** on port `27017`
- **Backend** on port `4000`
- **Frontend** on port `3000`

Visit: [http://localhost:3000](http://localhost:3000)

## API Endpoints

### Auth (`/auth`)

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/auth/register` | Register with email, password, first/last name |
| POST | `/auth/login` | Login and receive JWT cookies |
| POST | `/auth/refresh` | Rotate refresh token |
| GET | `/auth/me` | Get current user info |
| POST | `/auth/logout` | Clear auth cookies |

### Trips (`/api/trips`)

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/api/trips/generate` | Generate a new AI trip |
| POST | `/api/trips` | Save a trip |
| GET | `/api/trips/history` | Get all trips for current user |
| GET | `/api/trips/:id` | Get single trip with updated weather |
| DELETE | `/api/trips/:id` | Delete a trip |

## Environment Variables

| Variable | Description |
|----------|-------------|
| `PORT` | Backend port (default: 4000) |
| `MONGO_URI` | MongoDB connection string |
| `JWT_ACCESS_SECRET` | Secret for signing access tokens |
| `JWT_REFRESH_SECRET` | Secret for signing refresh tokens |
| `ACCESS_EXPIRES_IN` | Access token TTL (e.g. `1d`) |
| `REFRESH_EXPIRES_IN` | Refresh token TTL (e.g. `1d`) |
| `SUBMITTERS` | Project submitters shown in token payload |
| `CLIENT_ORIGIN` | Frontend origin for CORS |
| `OPENAI_API_KEY` | OpenAI API key for trip generation |
| `OPENWEATHER_API_KEY` | OpenWeatherMap API key for forecasts |

## Notes

- `.env` is **not committed** — never add it to git
- MongoDB data is persisted in a Docker volume (`mongo_data`)
- To reset the database: `docker exec web-mongo mongosh afeka_trip_auth --eval "db.users.deleteMany({}); db.trips.deleteMany({})"`
